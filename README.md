Python Caesar Cipher 🔐Un'implementazione robusta e modulare del celebre Cifrario di Cesare, completa di arte ASCII personalizzata, validazione degli input e gestione intelligente dei turni.Features 🎮Robust Input Handling: Sistema di validazione personalizzato con blocchi try-except per prevenire crash su stringhe non numeriche o opzioni errate.Modular Design: Separazione netta delle responsabilità con funzioni dedicate per cifratura, pulizia schermo e gestione dei flussi di input.Smart State Management: Il programma ricorda i nomi dei giocatori/utenti tra una sessione e l'altra, evitando richieste ridondanti se si decide di giocare ancora.Beautiful ASCII Art: Logo tematico caricato da un file esterno e visualizzato dinamicamente per un'esperienza utente immersiva.Safe Shift Logic: Supporta numeri di spostamento (shift) molto grandi grazie all'aritmetica modulare, garantendo il corretto "wrap-around" dell'alfabeto.Symbol Preservation: Mantiene inalterati spazi, numeri e caratteri speciali durante il processo di cifratura/decifratura.Game Rules 📋Objective: Cifrare o decifrare un messaggio spostando ogni lettera di un numero fisso di posizioni nell'alfabeto.Alphabet: Supporta l'intero set ASCII (maiuscole e minuscole) tramite string.ascii_letters.Encoding: Ogni lettera viene spostata in avanti di $n$ posizioni (es. 'A' con shift 1 diventa 'B').Decoding: Il processo viene invertito moltiplicando lo shift per $-1$ per tornare al messaggio originale.Non-Alphabetic characters: Simboli come !, @, # o gli spazi non vengono modificati.Project Structure 📁Plaintextcaesar-cipher/

Main Functions Overview:clear_screen() - Pulisce la console e stampa il logo per mantenere l'interfaccia ordinata.get_valid_input() - Valida le scelte dell'utente (es. encode/decode) con gestione degli errori.get_valid_nb() - Assicura che lo shift inserito sia un numero intero valido tramite try-except.encode_and_decode() - Il cuore del programma: esegue la traslazione dei caratteri.main() - Ciclo principale del programma con funzionalità di restart e persistenza dei dati.Requirements ✅Python 3.xNessuna dipendenza esterna richiesta (utilizza solo la libreria standard di Python).Installation & Setup 🚀Clona il repository:Bashgit clone https://github.com/FrontN/caesar-cipher.git

How to Use 🎯Avvia il programma:Bashpython main.py
Configurazione iniziale: Inserisci i nomi richiesti (verranno richiesti solo alla prima esecuzione).Scegli la modalità: Digita encode per cifrare o decode per decifrare.Inserisci i dati: Digita il messaggio e il numero di spostamento (shift).Risultato: Il programma mostrerà istantaneamente il testo elaborato.Continua: Digita yes per processare un altro messaggio o no per uscire.Technical Highlights 💡Platform Independent: Funziona perfettamente su Windows (cls) e Unix/Linux/macOS (clear).Clean Code: Funzioni documentate con Docstrings complete in formato NumPy per una manutenibilità superiore.List Comprehension: Utilizzo di logica compressa per una cifratura performante e leggibile.Persistence: Gestione ottimizzata del loop keep_going per migliorare la User Experience.Future Enhancements 🎯Supporto per alfabeti internazionali (Unicode/UTF-8).Funzionalità di "Brute Force" per tentare tutti i 26 shift possibili.Possibilità di caricare il testo da file esterni .txt.Interfaccia grafica (GUI) con Tkinter o PySide.Contributing 🤝I contributi sono benvenuti!
